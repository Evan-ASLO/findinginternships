# Preview-only onboarding comparison

Three working Next.js / JavaScript proposals for Internship & Coffee Chat. This artifact is not production authority and does not replace the no-build Cloudflare app, its data, access gates or source pipelines.

Users requesting access and users on their first approved login should understand four tools: Find jobs; private save/current-stage/notes tracking in My jobs; People with separate preparation and actual-draft/email approvals plus optional resume attachment; manual recording of a possible outcome. Canada eligibility is role/programme-specific. Saved/Archived are not applications. Replies are not automatically coffee chats. Offers/return offers are not promised and current statuses are not history.

All role/contact/draft/attachment/request/login/outcome data is authored fiction, explicitly labelled. All actions simulate locally with React state only, never requests, credentials, file uploads, provider calls or persistence. Tour progress is scroll progress in four equal quarters, not job success.

The user chooses after seeing three separate working compositions: pinned workspace, editorial chapter guide, SVG journey map. Warm incumbent CP cream/clay, Georgia display, Segoe UI primary, Light/Dark and reduced motion are fixed. No copied reference assets, competitor source, external fonts, new cloud services or image-provider credits.

Native scroll, backward progress, keyboard chapter links, skip/replay/back and responsive phone fallback are required. Sample actions stay independent of scroll. All routes remain local on loopback. Editable source/ZIP excludes dependencies, builds, credentials, private records and logs.
